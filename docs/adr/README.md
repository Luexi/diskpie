# Architecture decision records

ADRs capture decisions that materially affect correctness, security,
performance, portability, or contributor expectations.

- Copy `0000-template.md` to the next sequential number.
- Keep one decision per record.
- Link supporting research and benchmark evidence.
- Mark replaced records as `Superseded` rather than deleting them.
