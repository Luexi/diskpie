# DiskPie brand assets

The DiskPie mark is an original radial disk made from independently generated
geometry and color. No Scanner artwork or other product icon was used as an
input or reference.

## Files

- `diskpie-icon.png`: 512 x 512 RGBA source for the application and docs.
- `diskpie-icon.ico`: multi-resolution Windows icon containing 16, 20, 24, 32,
  40, 48, 64, 128, and 256 pixel images.

Both assets are distributed under the repository's `MIT OR Apache-2.0` terms.

## Palette

| Role | Hex | Intended use |
| --- | --- | --- |
| Midnight | `#062F57` | Dark surfaces, large branches, and icon silhouette |
| Current | `#05BCEB` | Primary focus, scan progress, and cool chart families |
| Ember | `#F79A1E` | Warm chart families and important non-destructive emphasis |
| Porcelain | `#FEFBF0` | Dividers and high-contrast detail on dark surfaces |
| Slate | `#20242B` | Dark-theme application background |

Chart colors may derive stable variations from these anchors, but text and
selection contrast must be measured in both light and dark themes.

## Generation record

The mark was created on 2026-08-02 with OpenAI's built-in image generation
tool from a text-only prompt for an original flat, vector-friendly combination
of a storage disk and sunburst. The prompt required a centered small-size
silhouette, a navy/cyan/amber/off-white palette, no text or watermark, and no
resemblance to platform or existing disk-analyzer logos. A flat magenta
background was removed locally, and the accepted output was downsampled with a
high-quality filter for the PNG and Windows ICO assets.
